# Celestial

小型AI群(ワーカー)と、それを束ねる管理AIで、さまざまな仕事をこの PC の中だけで処理するソフトです。
使うほど速く・正確に・省エネになり、自分専用のAIを学習して育てることもできます。
Android アプリから、会話の続き・PC の遠隔操作・ファイルのやり取りができ、スマホの中のAIだけでも動きます。

- PC 側のコアは Python 標準ライブラリだけで動きます(AI は Ollama)。
- スマホとは Tailscale のアドレスで直接つながり、外部のサーバーを経由しません。

## はじめかた

### PC

1. [Ollama](https://ollama.com) を入れ、モデルを入れます(例: `ollama pull gemma3:4b`、`ollama pull qwen2.5:1.5b`)。
2. [Celestial.cmd](Celestial.cmd) をダブルクリックします。初回は自動でセットアップし、専用のウィンドウで画面が開きます。

入れておくと使える機能が増えるモデル:

| モデル | 用途 |
| --- | --- |
| `gemma3:4b` | 画像の読み取り(添付画像・画面を見る道具)。計測で最も正確なことが多い |
| `qwen2.5:1.5b` | 速い下書き役。自信のない回答だけ、より正確なAIが答え直す |
| `bge-m3` | 言い回しが違っても、同じ趣旨の過去の良い回答を手本にする |

### スマホ(Android)

1. PC とスマホの両方で Tailscale にログインしておきます。
2. PC の画面の「スマホ連携」を開くと、QR コードと6桁の番号が出ます。
3. スマホのカメラで QR コードを読み取り、開いたページの「アプリをダウンロード」でアプリを入れます(初回のみ)。
4. 同じページの「Celestial アプリで接続する」を押すと登録が終わります。アプリの「設定」→「PC と接続」で、アドレスと番号を手で入れることもできます。

- 番号は10分間・1回だけ有効です。8回まちがえると無効になります。
- 初めてスマホからの接続を受け付けるとき、Windows のファイアウォールの確認が出ることがあります。Tailscale のネットワークからの接続を許可してください。
- 登録した端末は「スマホ連携」の一覧から名前の変更・登録の取り消しができます。

## できること

### 会話(PC・スマホ共通)

- 依頼に合った担当(一般・コード・計算と推論・要約・翻訳・文章作成・抽出)へ振り分け、実績の良いAIが答えます。
- 長く複合的な依頼は、管理AIが分解して複数のAIに分担させ、結果をまとめます。
- 画像を添付して質問できます(画像を扱えるモデルが自動で選ばれます)。
- 文字のファイル(テキスト・Markdown・CSV・JSON・プログラムなど)を添付して、要約や質問ができます。
- 会話の流れを踏まえて答えます(「それを英語にして」などの続きの依頼)。
- 回答の「もう一度」で、キャッシュを使わず検証つきで答え直します。自分の依頼は「直して送る」で入力欄に戻せます。
- 回答の「保存」で、Word・Excel(表を含む回答)・PowerPoint のファイルにできます。スマホではダウンロードフォルダに保存します。
- 最初のやり取りのあと、会話に内容を表す短い題名を AI が付けます(例:「4月の店舗別の売上を表にまとめて。東京 1,2…」→「店舗別売上表」)。読み込み済みのAIを使うので 0.1〜0.5秒で済み、自分で付けた題名は変えません。
- 「良い」「悪い」の評価を付けると、手本の記憶・モデル選び・キャッシュにすぐ反映されます。
- 会話は PC とスマホの間で同期されます。スマホで始めた会話を PC で続けることも、その逆もできます。
- **あなたに合わせる**: 設定の「AIへの指示」(答え方の好みなど)と「覚えていること」を、PC とスマホのすべての会話で使います。会話で「覚えて: 〜」「〜と覚えておいて」と頼むと覚え、「忘れて: 〜」で消え、「何を覚えてる?」で一覧が出ます(この3つはAIを呼ばずに即答)。指示を変えると、それより前に作った回答はキャッシュから使いません。
- **今日の日付**: 日付や時刻が関わる依頼(「今日は何曜日?」「大晦日まであと何日?」など)には、今日の日時を渡します。小さいAIは日付の計算を誤るので、日数・曜日・「100日後」などはプログラムで計算した値を渡し、短い日付の質問には計算した値でそのまま答えます。こうした依頼はキャッシュを使いません。
- **最新のニュース**: 「ニュース」「最新」などを求められたとき、ネットの利用を許可していれば、公開されている見出し(RSS)を取得して、それだけをもとに要約し、媒体名・日付・出典を付けます。許可していないときは、最新の情報は取得できないと最初に伝えます(小さいAIは、学習した古い知識から「最新ニュース」を作り上げてしまうため。実際にスマホからの依頼で起きたので直しました)。こうした依頼はキャッシュを使いません。
  - 話題を読み取って、取ってくる先を変えます。話題なし(「今日のニュース」)は NHK・BBC の主なニュース、分野(「経済ニュース」「海外のニュース」「tech news」)は NHK・BBC のその分野、ほかの話題(「AIに関する最新ニュース」「大谷翔平の最新ニュース」「AIや半導体のニュース」)は Google ニュースの検索で直近1週間を探します。見つからなければ、そう伝えます。
  - 検索の結果には迷惑な記事が混ざります(「AI」の検索では、見えない文字と埋め込み前の型が残った成人向けの宣伝が、1つの媒体から99件中75件来ました)。そうした見出し・広告・株価のページを除き、1つの媒体は3件までにして、検索の関連の強い順に選んでから新しい順に並べます。スマホから実際に来た「aiに関する最新ニュースをたくさん取得し、要約して」で、エヌビディアの CEO 辞任・Microsoft の障害・Sakana AI の上場計画・米国の AI 規制法案などの11件を、4秒ほどで要約できることを確かめました。
- **覚えますか**: 発言に利用者自身についての事実(好み・習慣・仕事・予定など)があると、判断の機能(下の「判断」)で見分けて、回答の下に「覚えますか: 私は花粉症で春が苦手。」のように提案します。押すと覚えます。8件の確認では、本人の話の5件中3件で提案し、本人の話でない3件には出しませんでした。

### 自動化(n8n のようなワークフロー)

画面の「自動化」で、きっかけと手順をつないで仕事を自動で動かします([flows.py](src/celestial/flows.py))。

| きっかけ | 手順 |
| --- | --- |
| 手動(PC・スマホから)、決まった時刻(曜日つき)、一定の間隔、Webhook(鍵つきのアドレスに送ると動く。`?wait=1` で結果を返す)、作業フォルダへのファイルの追加 | AIに頼む、判断する、ウェブページを読む、ウェブに送る、ファイルを読む・書く、文書を作る(Word・Excel・PowerPoint)、コマンドを実行、通知する(スマホ・PC)、条件に合わなければ止める、文章を組み立てる、待つ |

- 前の手順の結果は `{{prev}}`・`{{step2}}`、きっかけの内容は `{{trigger}}`(JSON なら `{{trigger.項目}}`)、今日の日付は `{{date}}`・`{{weekday}}` で差し込めます。判断の確率は `{{step1.probability}}`。
- 「AIで作る」に「毎朝8時に〜してスマホに通知」のように書くと、きっかけと手順の下書きを作ります(下書きは止めた状態で作るので、確かめてから有効にします)。
- ファイル・文書・コマンド・ウェブの手順は、エージェントと同じ道具を通して動くので、作業フォルダの外には届かず、書き換えの前にはバックアップが残ります。設定で許可していない種類の手順は、理由を記録して止まります。
- 自動化は確認なしで動くため、作る・変えるのは PC の画面からだけです。スマホからは、動かす・止める・実行の記録(手順ごとの結果)を見ることができます。

### プロジェクトを作る・フォルダの中を編集する(Codex や Claude Code のように)

- エージェントで「〜アプリを作って」と頼むと、**計画 → ファイルを1つずつ書く → 構文とテストで確かめる → 直す** の手順でプロジェクトを作ります([project.py](src/celestial/project.py))。小さいAIは1回の応答で多くのファイルを書き分けられないので、ファイルごとに、計画とそれまでのファイルを見せて書かせます。テストが落ちたら、テストを仕様として本体を直させ、同じ食い違いが残ればテストのほうを計画に合わせます。書く前に、計画をまとめて1回だけ許可を求めます。
- 実際に「数当てゲームの CLI アプリをテストつきで作って」で試し、12.7 秒で4ファイルを作り、テストに合格し、遊べることを確かめました(qwen2.5-coder:7b)。
- エージェントが変えたファイルは、Claude Code のようにファイルごとの増減(+12 −3)と差分で表示します(PC・スマホ)。
- エージェントが作業するフォルダは、作業フォルダの中から会話ごとに選べます(PC の画面の「フォルダ」)。

### 判断(Jev のような System 1)

文章を作らずに、決まった選択肢(省略時は はい/いいえ)から1つを、確率つきで選びます([decide.py](src/celestial/decide.py))。AIに選択肢の記号を1語だけ答えさせ、その1語目の確率の分布(Ollama の top_logprobs)から選択肢ごとの確率を出すので、0.05〜0.2秒で済みます。

- 使える場所: 画面の「判断」、自動化の「判断する」手順(判断で分けて、後の手順に確率を渡す)、`POST /api/decide`(スマホや外のアプリから)、「覚えますか」の見分け。
- **較正**: AIの確率は自信過剰になりがちです(gemma3:4b は誤答でも 99.99% と言う)。正解の分かっている判断(文章の意味を読み取る30問と、担当の振り分け55問)をAIごとに解かせ、温度を学んで直します(温度スケーリング)。判断には、意味の判断で最も正確だったAIを使います。
- 計測の例(2026年11月):

| AI | 意味の判断(30問) | 担当の振り分け(55問) | 較正誤差(較正前→後) |
| --- | --- | --- | --- |
| gemma3:4b | 27問(90%) | 33問(60%) | 0.112 → 0.047 |
| qwen2.5:1.5b | 22問(73%) | 50問(91%) | — |

  判断の得意不得意は課題の種類で変わり、大きいAIが良いとは限りませんでした。振り分けだけで選ぶと、「本人の話か」の判断を半分しか当てられないAIが選ばれたため、意味の判断で選ぶようにしています。

### AIエージェント

「エージェント」をオンにすると、AIが道具を使いながら自分で段取りを組み、目標まで進めます。

| 種類 | 道具 | 使える条件 |
| --- | --- | --- |
| 基本 | 計算(正確な四則演算・関数)、専門のAIへの依頼 | いつでも |
| ファイル | 一覧・名前で探す・読む・中身を検索 | 作業フォルダを設定したとき |
| ファイルの変更 | 書く・部分を書き換える・追記・フォルダ作成・移動・コピー・削除・元に戻す | 「ファイルの変更を許可」 |
| Office 文書 | Word・Excel・PowerPoint のファイルを作る。Word・PowerPoint は読む、Excel は CSV として読み・書き換え・行の追記もできる | 「ファイルの変更を許可」 |
| 実行 | Python の実行・コマンドの実行(テストなど) | 「コマンドと Python の実行を許可」 |
| PC 操作 | アプリやファイルを開く・文字入力・キー操作・クリック・スクロール・ウィンドウの切り替えと終了・画面を見る・クリップボード・音量・再生の操作・PC の状態・実行中のプログラム | 「PC の操作を許可」 |
| ネット | Wikipedia で調べる・ウェブページを読む | 「ネットの利用を許可」 |

安全のための決まり([tools.py](src/celestial/tools.py)):

- ファイルの道具は作業フォルダの外に届きません。書き換え・削除の前に必ずバックアップを取り、「元に戻す」で戻せます。
- 影響のある操作(ファイルの変更・実行・入力・クリック・アプリを開く など)の前に、内容を見せて許可を求めます。PC でもスマホでも許可できます。
- 文字入力やキー操作は、送り先のウィンドウを確かめてから行います。
- AIが「やりました」と答えても、実行記録に成功した操作がなければ、回答の先頭に訂正が付きます(小さなモデルは、やっていないことをやったと言うことがあるため)。
- ネットの道具は公開されているページだけを読み、家庭内の機器やこの PC 自身には触れません。

### スマホアプリ

| 画面 | できること |
| --- | --- |
| 会話 | スマホの中のAIか PC のAIかを選んで質問。PC ではエージェントも使え、操作の許可もスマホからできる。音声入力(入力欄のマイク。できれば端末の中だけで文字にする)、音声会話(手を使わずに、聞く→答える→読み上げる→また聞く を繰り返す。「終わり」で止まる)、「覚えますか」の提案、エージェントが変えたファイルの差分、画像・文字のファイルの添付、ほかのアプリからの共有の受け取り、回答の読み上げ(記号やコードは読まず、表は1行ずつ区切って読む。読み上げ中はボタンが「止める」に変わる)と共有、出典の表示、回答を Word・Excel・PowerPoint で保存 |
| PC操作 | 自動化(PC で動くワークフロー)を動かす・止める・記録を見る。PC の画面を見ながら、タップでクリック・ダブルタップ・長押しで右クリック・上下になぞってスクロール。「拡大」で拡大した表示のまま細かい所も操作できる。キーボード入力、よく使うキー、アプリやURLを開く、ウィンドウの切り替え、クリップボードのやり取り、音量・再生の操作、PC のロック |
| ファイル | PC の作業フォルダを見る・ダウンロード(途中から再開できる)・アップロード・フォルダ作成・削除(バックアップに移動) |
| AIモデル | PC に入っているモデルをスマホに取り込み、スマホの中で動かす。速さの計測 |
| 設定 | PC との接続、あなたに合わせる(AIへの指示・覚えていること)、PC への送信(文字・URL・クリップボード)、PC からの受信箱、見た目、通知 |

- スマホの中のAIは llama.cpp で動き、通信なしで答えます。CPU の機能(dotprod / i8mm)に合わせて最適な版を自動で選びます。
- スマホの中のAIも、PC から同期した「AIへの指示」「覚えていること」と今日の日付を使います(PC につながっていないときは、前に受け取った内容)。「覚えて」などと短い日付の質問は、PC と同じ決まりでAIを使わずに答えます。
- 音声入力は、端末の中で文字にできる場合はそれを使い(Android 12 以降の端末内の音声認識)、できない場合は端末の音声認識サービスにオフラインを優先して頼みます。
- PC の画面は JPEG で送り、変化がないときは送りません。画面が動いている間は速く、止まっている間はゆっくり確かめます。
- PC で回答が終わったとき、スマホに通知できます。

## 精度と速さの工夫

```
依頼 → キャッシュ → 振り分け(学習済みルーター → 管理AI → キーワード)
     → 担当のAIが回答(実績で選ぶ)
         ├ 出だしを確かめる: 自信がない・言語を取り違えた → より正確なAIが答え直す
         └ 事実の短い質問で自信がない → Wikipedia で確かめて答え直す(ネット許可時)
     → [検証] → 記録・学習
複合的な依頼は 管理AIが分解 → ワーカー群が並列処理 → 統合
```

| 仕組み | 効果 | 実装 |
| --- | --- | --- |
| 回答キャッシュ | 同じ依頼は計算なしで即答。悪い評価で無効になる | [store.py](src/celestial/evolve/store.py) |
| 学習済みルーター | 管理AIの振り分けを覚え、自信があれば管理AIを呼ばない | [router.py](src/celestial/evolve/router.py) |
| 振り分けの安全策 | 「コード」「翻訳」「抽出」「要約」は、依頼にそれらしい手がかりがあるときだけ選ぶ(メールアドレスの抜き出しをコードの担当に回す、などの自信満々の誤りを防ぐ)。55問の振り分けは 50→53問が正しくなった | [workers.py](src/celestial/workers.py) |
| モデル選び | 担当ごとに「品質 − 所要時間」の実績が良いAIへ寄っていく(UCB)。精度の計測結果を事前の実績として混ぜる | [manager.py](src/celestial/manager.py) |
| 経験記憶 | 良い評価の回答を、似た依頼の手本として渡す。埋め込みモデルがあれば意味の近さで探す | [memory.py](src/celestial/evolve/memory.py) |
| 確からしさでの答え直し | 回答の出だし(40トークン)の確率から自信を測り、低ければ打ち切って、計測で最も正確なAIが答え直す。打ち切るまで画面には出さない。境目は計測の結果から学ぶ | [manager.py](src/celestial/manager.py) |
| 言語の取り違えの防止 | 日本語の依頼には日本語で答えるよう明示する。それでも中国語や英語で答えたら答え直す | [manager.py](src/celestial/manager.py) |
| 事実の裏付け | 事実の短い質問で自信がないときだけ Wikipedia を調べ、資料を見せて答え直す。検索で当たった本文の箇所を資料の先頭に置き、「長さ順の日本の川一覧」のような順位の一覧には「1位は信濃川」と書き添える(名前の並びだけでは小さいAIが読み取れないため)。出典を表示する | [ground.py](src/celestial/ground.py) |
| 日付の計算 | 日付が関わる依頼にだけ今日の日時を渡し、日数・曜日はプログラムで計算した値を渡す。「大晦日まであと何日?」は 0/2 問から正解に、短い日付の質問は計算でそのまま答える | [manager.py](src/celestial/manager.py) |
| 繰り返しの打ち切り | 小さいAIが同じ文を書き続け始めたら、その場で止めて1回分だけを残す(PC・スマホとも) | [base.py](src/celestial/backends/base.py) |
| 入れ替えを避ける | 読み込み済みのモデルを優先し、メモリからほかのモデルを追い出すような選び方は、はっきり正確なときだけにする | [manager.py](src/celestial/manager.py) |
| 公平な比較 | 課題集が変わったら、今の課題集で測った結果だけでモデルを比べる | [store.py](src/celestial/evolve/store.py) |
| 自作AI | 普段の利用と自習のデータで小さなモデルを学習し、得意な担当で使う | [train.py](src/celestial/train.py) |

### 確からしさでの答え直しについて

AIは各トークンを出すときの確率を返せます。出だしの平均の対数確率が低い回答は、誤答であることが多いと分かりました。

予備実験の結果(50問。回答の出だし40トークンの、対数確率の平均):

| | 正解の回答 | 誤答 |
| --- | --- | --- |
| qwen2.5:1.5b の平均 | -0.25 | -0.40 |

答え直す境目は、モデルを固定した精度の計測で記録した「問題ごとの確からしさと正誤」から、正解数が最も多く、その中で最も速くなる値を選びます(計測がまだなら -0.25)。計測するたびに学び直します。

小さいモデルは日本語の質問に中国語や英語で答えてしまうことがあります。日本語で答えるよう明示すると、12問中5問しか日本語でなかったのが12問とも日本語になり、正解も4問から8問に増えました。

## Word・Excel・PowerPoint

追加のライブラリなしで、Office のファイルの中身(ZIP に入った XML)を直接書きます([office.py](src/celestial/office.py))。エージェントの道具と、回答の「保存」の両方で使います。

| 種類 | 内容 |
| --- | --- |
| Word | 見出し・箇条書き(番号は段落ごとに 1 から)・表・コード・太字 |
| Excel | 1行目は見出し(固定・強調)。数・桁区切り(1,200)・パーセント・単位つきの数(1,200円、¥1,500、12件、▲300円)は数として入れ、単位は表示の形で見せるので、合計などの数式が正しく計算されます。複数のシートも作れます |
| PowerPoint | 見出しごとに1枚(表紙・箇条書き・表)。見出しのない回答は、内容を区切ってスライドにします |

Excel の数式の工夫:

- `=SUM(above)` と書くと、見出しの下からその行の上までの範囲になります(表の大きさを数えなくてよい)。
- 「合計」の行の SUM の範囲が短すぎる・自分の行まで含めて循環参照になる、といった小さいAIの誤りを直します。
- AI が数で書いた「合計」「平均」は、上の行の合計・平均と一致するときだけ数式に置き換えます(値は変えず、あとでデータを直しても合計が追従します)。合わないときはそのままにします。

AI は両端の `|` を省いた表(`月 | 売上` の次の行が `--- | ---`。GFM では正しい書き方)もよく書くので、PC の画面・スマホ・Office の書き出しのどれでも表として扱います。

作ったファイルは、Word・Excel・PowerPoint で開いて確かめています(Excel では数式の結果も計算させて確認)。

## 精度の計測

答えを機械的に採点できる課題集([bench_tasks.py](src/celestial/bench_tasks.py)、55問)を解かせ、正解率・振り分けの正しさ・平均の所要時間を記録します。

- 計測は会話の履歴にもキャッシュにも触れないので、学習状態を変えません。
- `--model` で全ワーカーを1つのモデルに固定でき、モデル同士や自作AIとの比較に使えます。固定した計測の問題ごとの結果は、答え直しの境目の学習に使われます。
- 自動でのモデル選びは、今の課題集で計測したモデルの中から行います。新しく入れたモデルは、「精度の計測」で測ると候補に入ります(`celestial bench --model 名前`)。
- コードの課題は、モデルが書いた Python コードをこの PC 上で実行して採点します。`--run-code`(画面では「コードの課題も採点する」)を付けたときだけ対象になります。
- 独自の課題集は `--tasks 課題.jsonl` で指定できます。

### 計測結果の例

組み込みの55問(計算と推論16・一般の知識22・翻訳5・抽出5・要約2・コード5)。2026年11月、GPU は RTX 5060(8GB)。

| 方式 | 正解 | 1問の平均 |
| --- | --- | --- |
| qwen2.5:1.5b だけ | 32 | 0.70秒 |
| gemma3:4b だけ | 48 | 1.41秒 |
| qwen2.5-coder:7b だけ | 46 | 2.06秒 |
| 自作AI(celestial-base)だけ | 21 | 0.52秒 |
| 自動(改良前: 古い課題集の結果も混ぜて選び、入れ替えを考えない) | 46 | 2.45秒 |
| 自動(答え直し・入れ替えを避ける・振り分けの安全策) | 48 | 1.06秒 |
| 自動(上に加えて Wikipedia での裏付け) | 50 | 1.25秒 |

- 自動では、計測で最も正確な gemma3:4b と同じ正解数を、25%短い時間で出せています。抽出・要約のように小さいモデルで足りる担当は速いモデルが答え、自信がなければ gemma3:4b が答え直します。
- Wikipedia での裏付けは、「光の三原色」「世界一広い海洋」のような言い間違いを直しました。検索で答えの載った項目が見つからない問題(初代内閣総理大臣など)は直せません。
- 小さいモデルは回答にばらつきがあり、同じ設定でも数問ほど上下します。
- 繰り返しの打ち切りで、自作AIの平均は 4.21秒→0.52秒、qwen2.5:1.5b は 1.07秒→0.70秒 になりました。

## 自作AI

Celestial 自身が小さなモデルを学習し、配布モデルと同じ土俵で使い分けます。

```
自習(教師役のAIが練習問題を作って解く) ─┐
普段の利用(悪い評価を除いた回答)      ─┴→ 学習 → 自作AI → 精度の計測 → 担当選びに反映
```

| 手順 | コマンド | 内容 |
| --- | --- | --- |
| 自習 | `celestial study --per-role 15` | 計測で最も正確なAIが、担当ごとに練習問題を作って解く。依頼文だけで答えられない問題や、計測の課題に似た問題は除く。`--review` で保存済みのデータを見直す |
| 学習 | `celestial train` | 基礎モデル(既定は Qwen2.5 0.5B)に LoRA で教え込み、`celestial-v1`, `v2`… として保存。終わると Ollama に書き出し、精度を計測する |
| 利用 | (自動) | 自作AIは他のモデルと並んで候補になり、得意な担当で選ばれる。自信のない回答は、より正確なAIが答え直す |

学習には追加のライブラリが必要です(合計で数GB)。

```bash
uv pip install torch --index-url https://download.pytorch.org/whl/cu128
```

```bash
uv pip install transformers peft gguf
```

- 基礎モデルを凍結して LoRA の重みだけを更新し、bf16 の混合精度と長さをそろえたバッチで速くしています。語彙への出力は回答部分の位置だけ計算します(8GB の GPU に収めるため)。
- 周回ごとに検証用データで確かめ、最も良かった時点の重みを採用します。
- 学習後は LoRA を基礎モデルに合成して GGUF に変換し、Ollama に登録します([ollama_export.py](src/celestial/ollama_export.py))。スマホにも取り込めます。

## 安全とプライバシー

- 画面(PC の中)は 127.0.0.1 だけで待ち受け、他のサイトからの呼び出しは拒否します。プロキシを通った通信(X-Forwarded-For や Tailscale Funnel の印があるもの)も拒否するので、誤って Funnel などで公開しても鍵なしでは使えません。
- スマホからの接続は Tailscale のアドレスだけで受け付け、登録した端末の鍵(PC にはハッシュだけを保存)がなければ何もできません。
- 作業フォルダ・道具の許可・スマホからの接続と操作の許可は、PC の画面からしか変えられません。
- 「スマホからの PC 操作を許可」をオフにすると、画面の送信と遠隔操作を止められます。
- ネットを使うのは「ネットの利用を許可」をオンにしたときだけです(Wikipedia で調べる・指定されたページを読む・事実の裏付け・最新のニュース)。ニュースの検索に送るのは、依頼から読み取った話題の言葉(「AI」など)だけです。

## 制限

- 小さなローカルのAIなので、知識や推論は大きなクラウドのAIに及びません。答え直しと裏付けで誤りを減らしていますが、誤答はあり得ます。
- 事実の裏付けは Wikipedia の利用回数の制限に当たると、しばらく行いません(そのあいだは裏付けなしで答えます)。
- PC 操作の道具と遠隔操作は Windows 向けです。
- Flutter の Windows 版は、会話と設定だけです(学習状況・精度の計測・スマホ連携などは Celestial.cmd の画面で行います)。
- 自作AIの Ollama への書き出しは Qwen2 / Qwen2.5 系の基礎モデルに限ります。
- Office のファイルは、Word・PowerPoint は作り直しで更新します(部分の書き換えは Excel だけ)。グラフ・画像・既存の書式は扱いません。
- スマホの中のAIだけで話した会話は、題名の自動付与の対象外です(依頼の最初の行が題名になります)。
- 事実の裏付けは、Wikipedia の検索で答えの載った項目が見つからない質問(「人口が一番多い都道府県」など)は直せません。
- 「覚えて」の判断は決まった言い方だけです(「これを覚えて」のように会話の流れが必要なものは、普通の依頼として扱います)。
- 「覚えますか」の見分けは取りこぼしがあります(確認した8件では、本人の話の5件中2件を見逃しました)。
- プロジェクトの作成は、小さいローカルのAIで作れる規模(数ファイル)向けです。テストの実行は「コマンドと Python の実行を許可」したときだけ行います。
- 音声入力・音声会話は、端末の音声認識サービスが必要です(エミュレータでは音声が入らないため、聞き取りそのものは実機で確かめる必要があります)。
- GPU を使う処理(学習・自習・計測)を同時に重ねると、メモリ不足で失敗することがあります。
