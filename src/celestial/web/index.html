記録 ライブ・見張りの結果

    自動化

    きっかけ(手動・時刻・間隔・Webhook・ファイルの追加)と手順(AI・ウェブ・ファイル・文書・コマンド・通知・条件)をつないで、仕事を自動で動かします。

    判断

    文章を作らずに、決まった選択肢から1つを確率つきで選びます(Jev のような System 1)。自動化の分岐や、覚えるべき発言の見分けにも使っています。

    スマホ連携

    Tailscale 経由で、スマホからこの PC の AI を使ったり、会話を同期したり、PC を操作したりできます。

    学習状況

    使うほど速く、少ない計算で答えられるようになっているかを確かめます。

    精度の計測

    答えの決まった課題を解かせて自動採点します。計測は学習状態を変えません。

    コードの採点では、AIが書いた Python コードをこのPC上で実行します。

    空のフォルダで、ファイル作成・バグ修正・整理・git・Excel・サーバーなど 9 件の作業を実際に行わせ、できたファイルで採点します(1件 1〜3 分)。結果は、エージェントのAIの自動選択に使われます。

    モデルと設定

    利用できるAIと、学習のしかたを確認・変更します。

    知識ベース

    資料・メモ・フォルダ・ウェブページを取り込んで、質問のたびに必要な根拠を自動で参照します

    作業するフォルダを選ぶ

    エージェントは、選んだフォルダの中で作業します。
